# 📚 Library Management System – MySQL Mini Project

## 📌 Project Objective

Design a simple Library Management System using MySQL and perform basic SQL operations.

## 🗄️ Database

**Database Name:** `library_management`

## 📋 Tables

### 1. Books
- book_id
- book_name
- author
- category
- price
- quantity

### 2. Students
- student_id
- student_name
- email
- phone
- city

### 3. Issued Books
- issue_id
- book_id
- student_id
- issue_date
- return_date

## 📊 Data Inserted

- 10 Books
- 10 Students
- 10 Issued Book Records

## 🔍 SQL Operations Performed

1. Display all books
2. Display all students
3. Display books with price greater than ₹500
4. Display books in Programming category
5. Display students from Visakhapatnam
6. Display books in ascending order of price
7. Display books in descending order of price
8. Find total number of books
9. Find average book price
10. Find highest book price
11. Find lowest book price
12. Display students whose names start with A
13. Display books whose names contain Python
14. Update book price
15. Update student phone number
16. Delete a student record
17. Display issued book details
18. Display books that are currently not returned
19. Count issued books
20. Display book and student details using JOIN

## 📝 Project Explanation

This project demonstrates a basic Library Management System using MySQL. It manages books, students, and issued books and demonstrates basic SQL operations including filtering, sorting, aggregation, updating, deleting, and joining data.
